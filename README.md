# Portfolios

Since 2023, Hivemind Robotics has maintained one of the fastest-growing resources for spreading knowledge of the competitive judging process. This repository represents our off-season effort to rebuild the [Portfolios resource](https://portfolios.hivemindrobotics.net/) from the ground up, resolving technical debt and architectural issues caused by previous mid-season fixes.

## Project Status

**Note** that this is an active work-in-progress repository. If you're looking for the current production deployment, see the main repository here: [hivemindhq/portfolios](https://github.com/hivemindhq/portfolios). This repository serves as a development ground for a revision coming in the next few months.

## Contribution Policy

### AI Usage Policy

We maintain a strict policy against the use of AI-generated code for contributions to either of our repositories. We believe it is vital for our maintainers to understand exactly what is being shipped into our production environment. Please ensure all contributions are your own original work.

### How to help

If you are interested in helping us improve this resource, please ensure you are targeting the correct repository:

- Current Production Site: [hivemindhq/portfolios](https://github.com/hivemindhq/portfolios)
- New Version: This repository!
